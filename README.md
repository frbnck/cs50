# CS50: Introduction to Computer Science

All my code, problem sets, and projects for CS50x: Introduction to Computer Science, offered by Harvard University.

### [Week 1](./week1)

This week introduced the C programming language, transitioning from Scratch's visual blocks to written source code. Topics covered include:

- Compiling: Converting source code to machine code using make
- Hello World: Writing, compiling, and running a basic C program
- Variables & Types: int, char, float, double, string
- Conditionals: if, else if, else, and comparison operators
- Loops: while, for, and do while
- Functions: Creating custom functions, prototypes, and return values
- CS50 Library: Using get_string, get_int, get_char, get_float
- Command Line: Basic Linux commands (ls, mkdir, cd, mv, rm, cp)
- Limitations: Integer overflow, truncation, and floating point imprecision
